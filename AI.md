# AI Usage Declaration

**Project:** Cloud-Based Deployment of TripWise Travel Planner  
**Course:** INFS3208 Cloud Computing

ChatGPT (OpenAI) was used as a supporting tool during this project, primarily for guidance on Docker configuration, deployment procedures, troubleshooting, and documentation.

AI assistance was also used to help structure and refine the project proposal and to create the README.md file which had to be very explicit, clear, and straight-forward.
